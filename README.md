# OFoster Samples

Standalone examples for the OFoster library.

## Requirements

- Odin nightly
- The OFoster library checked out next to this project as `OFoster`
- SDL3 runtime available from the Odin distribution

## Run an example

From this directory:

```bat
run.bat
run.bat feature
run.bat batcher
run.bat spatial
run.bat calc
run.bat backend
run.bat app_composition
```

The default `basic` example keeps its update/render loop running until the
window is closed.
